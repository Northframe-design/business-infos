# Konzept: Bush Architects (Dallas, Texas)

Stand: 05.10.2026. Private Konzeptvorschau von Northframe, nicht öffentlich.

## Designrichtung
Large master-planned and mixed-use work that lives from big images: each project gets a full screen.

**Inspiration:** TARQ Studio (dark cinematic full-bleed slides, bracket captions, "next project" bar).

**Signature:** Twelve project slides stack and slide over each other, with a bracket caption and a "next" bar. The hero cross-fades three images.

## Inhalt (echt vs. Platzhalter)
- Echt von busharchitects.design: Project names, categories and locations from the site, services, partners and studio lead, address, phone, mail, the line "Transparent. Imaginative. Open."
- Offen: Most images on the source site are renderings; they stay labeled as such in the code comment. Recheck image rights before any public use.

## Technik
Statisches HTML/CSS/JS, GSAP und ScrollTrigger aus `../../_presentation/vendor/` (nur wo animiert), Schriften über Google Fonts (OFL). Vorschau: `leads-static` (Port 5180), Pfad `Architecture & Design/bush-architects/mockup.html`. Reduced-motion und Mobil (390 px) sind berücksichtigt.
