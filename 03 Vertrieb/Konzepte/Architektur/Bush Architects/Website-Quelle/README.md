# Bush Architects — Website-Quellpaket

Enthält das vollständige Mockup mit HTML, CSS, JavaScript, Bildern und den benötigten lokalen Animationsbibliotheken.

Startdatei: `leads/Architecture & Design/bush-architects/mockup.html`

Die Ordnerstruktur unter diesem Verzeichnis muss erhalten bleiben, weil die Dateien relative Pfade verwenden. Für die Animationen die HTML-Datei über einen lokalen Webserver öffnen; Google Fonts benötigen eine Internetverbindung. Die Bild- und Videodateien des Mockups sind enthalten, soweit sie im Website-Ordner liegen.
