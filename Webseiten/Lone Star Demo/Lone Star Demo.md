# Lone Star Demo – eigene Roofing-Demo-Seite

Die Showcase-Seite für Northframe (fiktive Firma "Lone Star Roofing Co.", Platzhalter-Daten). Wird später als Template für echte Kunden genutzt.

**Status:** live ✅ → https://lonestar-demo.pages.dev/
Scroll-Kamerafahrt: Haus → Zoom aufs Dach → Dach spaltet sich in 8 Lagen (gebaut von Codex).
Frühere Version mit Sturm-Intro: gesichert unter `roofing-template/_versionen/v1-sturm/`.

- Code: [GitHub](https://github.com/Northframe-design/website-business/tree/main/roofing-template)
- Hosting: Cloudflare Pages, Projekt `lonestar-demo`. Jeder `git push` auf `main` stellt automatisch neu online.
- Lokal ansehen: Terminal im Ordner `roofing-template/site` öffnen → `npm run dev`

Offen: Platzhalter wie `[City]`, `[4.9]`, `(555)` durch klar erkennbare Demo-Daten ersetzen, bevor wir die Seite Leads zeigen.
