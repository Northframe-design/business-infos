# Northframe — Brand identity

Zentrale Ablage fuer alle Markenmaterialien von Northframe: Logos, Farben, Schriften und spaetere Brand Guidelines.

## Ausgewaehltes Logo

- Variante 02 aus der NF-Dreieruebersicht: kleines nf mit geschwungenem f und Serifen.
- Datei: northframe-nf-black-transparent.png
- Format: PNG, 1536 x 1024 Pixel, transparenter Hintergrund.
- Schwarze Version fuer helle Hintergruende.
- Rasterdatei; keine SVG-/Vektordatei.
